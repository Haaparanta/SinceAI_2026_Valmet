## File format

```
ply
format binary_little_endian 1.0
comment Generated by EGS
element vertex 1506136
property float x
property float y
property float z
property float scale_0 … scale_2
property float rot_1
property float rot_2
property float rot_3
property float rot_0
property float f_dc_0 … f_dc_2
property float opacity
property float f_rest_0 … f_rest_44
end_header
```

- A standard **3D Gaussian Splatting** (3DGS) export. "EGS" is the exporting tool.
- **1,506,136** Gaussians, **59** `float32` properties each, so **236 bytes per record** (1,506,136 × 236 + header = file size).
- No faces, no normals, no labels, no camera poses. All semantics are ours to produce.

## Decoding each attribute

| Properties | Stored as | To get the real value | Notes |
|---|---|---|---|
| `x, y, z` | world position | as is | **y is up** in this scene |
| `scale_0..2` | log of the Gaussian's standard deviation per local axis | `exp(v)` | after cleaning, the largest axis is 4 mm (5th pct), 12 mm (median), 68 mm (95th pct) |
| `rot_1, rot_2, rot_3, rot_0` | quaternion, unnormalised | normalise; `rot_0` is the **real (w)** part | stored order puts `rot_0` **last**. Always read by name. Some rows hold absurd values (~1e34) and must be dropped |
| `f_dc_0..2` | spherical-harmonic degree-0 colour | `rgb = clip(0.5 + 0.28209479 × f_dc, 0, 1)` | mean colour after cleaning ≈ (0.56, 0.52, 0.45): a warm grey, matching the concrete room |
| `opacity` | logit | `sigmoid(v) = 1 / (1 + exp(-v))` | median opacity of kept Gaussians ≈ 0.26 |
| `f_rest_0..44` | higher-order SH (degree 3) | 15 coefficients × 3 colours, **channel-major** (all R, then G, then B) | only needed for view-dependent rendering; ignore for geometry |

The decoding matches the OpenUSD converter and the glTF `KHR_gaussian_splatting` spec, both summarised in [link 8](../../links/08-khronos-gltf-gaussian-splatting/README.md) and [link 9](../../links/09-nvidia-openusd-particle-fields/README.md).

## Data quality: most of the file is junk

Measured over all 1,506,136 records on 2026-11-06:

| Check | Gaussians | Share |
|---|---:|---:|
| All 59 properties finite (no NaN/Inf) | 1,309,240 | 86.9 % |
| Position finite | 1,490,977 | 99.0 % |
| Position finite but beyond ±100 units on some axis | 840,883 | 55.8 % |
| Position within ±100 but collapsed onto the origin (all axes \|v\| < 1e-6) | 78,297 | 5.2 % |
| Opacity > 0.1 (any position) | 1,042,737 | 69.2 % |
| Opacity > 0.5 (any position) | 386,804 | 25.7 % |
| **Kept by the strict filter below** | **289,859** | **19.2 %** |

So roughly four out of five Gaussians are floaters, broken records or near-transparent haze. Clustering or pathfinding on the raw file will fail.

## Scene geometry after cleaning

On the 289,859 kept Gaussians (1st–99th percentile, so stray points don't inflate it):

| Axis | From | To | Extent |
|---|---:|---:|---:|
| x | −4.74 | 3.86 | **8.60** |
| y (up) | −1.40 | 1.09 | **2.50** |
| z | −4.23 | −0.79 | **3.45** |

Height profile (number of Gaussians per y slice) has clear peaks:

| y | Gaussians in slice | What it most likely is |
|---|---:|---|
| **−0.95** | 32,769 (strongest) | **floor** |
| −0.88 / −0.81 | 24,315 / 10,858 | floor clutter, bottoms of objects |
| 0.35 | 12,091 | tops of tables, boxes and equipment (mid-height band) |
| **1.00** | 27,735 (second strongest) | **ceiling**, or the dense layer of overhead pipes just below it |

Floor-to-ceiling is therefore about **2.0 units**.

Watch out for **near-origin junk**: about 2,700 Gaussians pass the opacity and size filters but sit within 1 mm of (0, 0, 0). Left in, they form a fake dense "wall" at z ≈ 0 and a fake sheet at y ≈ 0 in any density plot. The filter below removes them.

The video shows a normal basement with roughly 2.5–3 m headroom, so **1 unit is probably not 1 metre**; the scan is likely scaled down by about 1.2–1.5×. Calibrate before quoting any distance: measure the door in the scan (a standard Finnish door leaf is about 2.1 m tall and 0.9 m wide) and derive the scale factor.

A coarse top-down density map (x to the right, z downwards) shows a dense band of walls and equipment along one long side and a sparser middle. The room is about 8.6 × 3.5 units in plan, so the walkable floor will be corridors roughly 1–1.5 units wide between equipment.

## Recommended cleaning pipeline

Apply in this order, then cache the result (e.g. `.npz`, ~5 MB) so later steps never read the 355 MB file again:

1. Drop any record with a non-finite value in any of the 59 properties.
2. Drop positions with `|x|`, `|y|` or `|z|` > 100.
3. Drop positions within 1 mm of the origin (`max(|x|,|y|,|z|) < 1e-3`).
4. Drop low-opacity Gaussians: `sigmoid(opacity) < 0.1`.
5. Drop oversized Gaussians: `max(exp(scale)) > 1` (smeared background blobs).
6. Drop rows whose quaternion norm is 0 or absurd (> 1e6), then normalise.
7. Optionally drop statistical outliers (Open3D `remove_statistical_outlier`) and crop to the 1st–99th percentile box.
8. Rotate to z-up if the rest of the pipeline expects it: `(x, y, z) → (x, −z, y)`.

## Reading it

Plain NumPy, no PLY library needed:

```python
import numpy as np

path = "Source-Data-Do-Not_change/Industrial Boiler Room (1).ply"
with open(path, "rb") as f:
    names = []
    while (line := f.readline().decode().strip()) != "end_header":
        if line.startswith("property"):
            names.append(line.split()[-1])
    g = np.fromfile(f, dtype=[(n, "<f4") for n in names])

A = np.stack([g[n] for n in names], 1)
xyz = A[:, :3]
opacity = 1 / (1 + np.exp(-np.clip(g["opacity"], -50, 50)))
scale = np.exp(np.clip(np.stack([g["scale_0"], g["scale_1"], g["scale_2"]], 1), -30, 30))
rgb = np.clip(0.5 + 0.28209479 * np.stack([g["f_dc_0"], g["f_dc_1"], g["f_dc_2"]], 1), 0, 1)

quat = np.stack([g["rot_0"], g["rot_1"], g["rot_2"], g["rot_3"]], 1).astype(np.float64)  # w, x, y, z
qnorm = np.linalg.norm(quat, axis=1)

keep = (np.isfinite(A).all(1)
        & (np.abs(xyz) <= 100).all(1)
        & (np.abs(xyz).max(1) >= 1e-3)          # near-origin junk
        & (opacity > 0.1)
        & (scale.max(1) < 1)
        & (qnorm > 1e-8) & (qnorm < 1e6))       # ≈ 289,859 Gaussians remain
quat = quat[keep] / qnorm[keep, None]
np.savez_compressed("boiler_clean.npz", xyz=xyz[keep], rgb=rgb[keep], opacity=opacity[keep])
```

Loading takes a few seconds and ~360 MB of RAM. If `numpy` is not installed: `uv run --with numpy python script.py`.

## Converting and viewing

| Goal | Tool |
|---|---|
| Quick look in a browser | SuperSplat, or any three.js Gaussian-splat viewer |
| Python viewer with overlays (boxes, path, avatar) | Viser (`add_gaussian_splats`) or Rerun (`Points3D` on the cleaned centres) |
| Point cloud processing | Open3D: load cleaned `xyz` + `rgb` into a `PointCloud` |
| Omniverse / OpenUSD | `py3dgsPlyToUsd.py --input <ply> --output <usd>` ([link 9](../../links/09-nvidia-openusd-particle-fields/README.md)). Run it on a **cleaned** PLY, or the junk will be converted too |
| glTF | re-pack as `KHR_gaussian_splatting` ([link 8](../../links/08-khronos-gltf-gaussian-splatting/README.md)) |

## What this means for the build

- **Segmentation input:** use cleaned Gaussian centres as a point cloud (~290k points). Colour is usable for separating red vessels, green labels and grey pipes.
- **Floor and navigation:** fit a plane near y ≈ −0.95, build a 2D occupancy grid from everything between floor + ~0.1 and floor + avatar height, inflate by the avatar radius and run A*.
- **Ceiling:** cut everything above ~0.9 before clustering, or pipes and ceiling merge into one huge cluster.
- **Scale:** carry a single `units_per_metre` constant through the pipeline so distances in the UI and in the copilot's answers can be corrected once the door is measured.
